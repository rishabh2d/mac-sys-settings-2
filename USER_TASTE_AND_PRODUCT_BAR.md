# User Taste And Product Bar

This file captures the product taste behind Mac Sys Settings 2 so new agents act like senior collaborators, not interns.

## What The User Values

- Real computer control over vague UI.
- Small tweaks that remove repeated annoyance.
- Settings that feel obvious once they exist.
- Premium compact utility design.
- Dense, useful panels over spacious marketing layouts.
- Short copy that explains the behavior and permission.
- System-level features that are ambitious but still honest about macOS limits.

## What To Avoid

- Placeholder settings.
- Dummy categories.
- Fake toggles.
- "Coming soon" controls.
- Big hero/landing-page style UI.
- Over-explaining obvious UI in the app.
- Long chat summaries when the user asked for a short reply.
- Repeating already-discussed research ideas as if they are new.
- Testing that leaves windows moved, apps hidden, overlays open, or focus stolen.

## UI Taste

- Mac System Settings inspired, but not a clone.
- Compact panel should feel like a premium menu bar utility: clean, dense, fast, and useful.
- Controls should be real rows, toggles, pickers, buttons, and status cards.
- Section headings and descriptions matter inside settings pages.
- Compact panel can use tile grids and direct actions.
- Use plain labels like Open, Reset, Apply, Choose, Restore.
- Do not show technical implementation language unless it helps the user decide.

## Setting Taste

Best settings are usually:

- per-app
- per-monitor
- per-device
- shortcut-driven
- context-aware
- reversible
- visible in a compact panel or menu bar
- clear about permission needs

The best ideas often sound like:

- "When this device connects, always do X."
- "When this app is focused, make Y different."
- "When this monitor appears, restore Z."
- "Give me one shortcut for this buried Mac setting."
- "Let me undo macOS chaos quickly."

## Research Taste

When researching new settings:

- Do not repeat Stage Manager, generic window snapping, layout presets, or the same menu bar clutter idea over and over.
- Search old Apple Discussions, Reddit, MacRumors, Ask Different, SuperUser, Hacker News, utility app reviews, and GitHub issues.
- Look for recurring phrases: "why can't macOS", "I wish Mac", "is there a way", "annoying", "keeps switching", "Finder always", "external monitor", "AirPods mic", "menu bar clutter".
- Return only ideas that could become settings or useful helper flows.

## Communication Taste

- Default to concise.
- If the user says "short reply", answer in one line.
- If the user asks "do you get it?", explain the behavior back briefly.
- If doing code, just do it and report the result.
- If something is blocked by macOS, say the concrete blocker and the closest real fallback.
