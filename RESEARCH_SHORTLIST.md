# Research Shortlist

This is the deduped shortlist of high-value next settings from web, Reddit, and Grok/X research. Use it when the user asks "what's next?" or wants to pick the next setting.

## Top Next Candidates

1. Audio device priority ranking: ranked mic/speaker fallback like Wi-Fi.
2. Quick AirPods/mic input lock: stop AirPods stealing microphone input.
3. Per-app audio routing: send Zoom, browser, music, etc. to different outputs.
4. Volume spike prevention on audio switch: smooth or cap volume when outputs change.
5. Bluetooth auto-reconnect blacklist: stop flaky/annoying devices from reconnecting.
6. Open/save dialog recent folders quick list: pinned/recent folders inside file pickers.
7. Finder New File Here: right-click/shortcut to create common file types in the current folder.
8. Finder search current folder lock: force Finder search to current folder by default.
9. Finder filename-first search: prioritize filename matches over file contents.
10. Finder lock folder view/sort: preserve view/sort per folder.
11. Login items group toggles: Work, Recording, Clean Startup profiles.
12. Menu bar icon context visibility: hide/show icons by app, state, or mode.
13. Keyboard shortcut conflict detector: show what app/system owns a shortcut.
14. Keyboard context menu key: open right-click menu from keyboard.
15. Keyboard layout per-window memory: remember input language per app/window.
16. Per-app gesture/mouse sensitivity: disable or tune gestures per app.
17. Cursor locator hotkey/wiggle: find pointer on large monitor setups.
18. Typing auto-DND: silence notifications while actively typing, resume after idle.
19. Per-app notification snooze: temporarily silence one app without full Focus.
20. Privacy permission dashboard: central page for missing Accessibility, Screen Recording, Input Monitoring, etc.
21. Settings change history: show what macOS/app setting recently changed.
22. Settings backup/migration: export/import Finder, Dock, keyboard, menu bar, and app settings.
23. Per-monitor scaling/refresh profiles: one-click external monitor quality presets.
24. Window position recall with monitor ID: restore windows after reconnect/sleep.
25. Lid close behavior profiles: sleep/stay-awake rules based on external monitor and power.
26. Sleep behavior per power source: different sleep/display rules on battery vs plugged.
27. Network drive reconnect button: remount saved NAS/server drives quickly.
28. iCloud Drive conflict resolver dashboard: find duplicates/conflicts and bulk-fix.
29. Clipboard paste preview with filter: searchable clipboard by app/source.
30. Screenshot auto-categorize by app/context: route screenshots into useful folders.

## Lower Priority / Ignore For Now

- Stage Manager variants.
- Generic basic window snapping.
- Repeated layout preset/grandma layout ideas.
- Per-display menu bar hiding until a reliable allowed macOS path exists.
- Dock per-monitor independent hide until macOS allows a clean implementation.
- Mission Control per-display tweaks unless a concrete safe path is found.
- Session-based one-time permissions.
- Permission grant without app relaunch.
- External device trust persistence.
- System accent color per-app override.
- Missed notification smart grouping.
- Generic Focus schedule automation.

## How To Use This List

When the user asks what to build next, suggest the top five that match their current mood and hardware:

- audio/device pain: choose audio priority, mic lock, Bluetooth rules
- file workflow pain: choose Finder New File, open/save folders, Finder search
- monitor pain: choose scaling profiles, window recall, lid close behavior
- focus pain: choose typing auto-DND, per-app notification snooze
- open-source polish: choose permission dashboard, shortcut conflict detector
