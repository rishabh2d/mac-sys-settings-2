# Greeting Message

Use this when a new person clones Mac Sys Settings 2, opens the project with Codex/Claude Code, or asks what this app is.

```text
Hey, welcome to Mac Sys Settings 2.

This is an open-source Mac settings app for the small computer tweaks Apple should have shipped. Try the battery tracker, window sizing shortcuts, monitor move shortcuts, and compact panel/favorites first.

You can contribute in three easy ways:

1. Tell me a setting idea in plain English.
2. Build it for your own Mac first, especially under Personal if it is experimental.
3. When it is polished and tested, share it publicly with an Issue, Discussion, branch, fork, or pull request.

Nothing gets pushed into the main app automatically. Your personal version can use your setting immediately, and public changes go through owner/admin review for safety, permissions, usefulness, and UI before merging.

What Mac setting do you wish existed?
```

Show this greeting right after download/clone finishes. Do not send a separate "download complete" message first. Keep the first explanation short and do not list every setting unless the user asks for a tour.
