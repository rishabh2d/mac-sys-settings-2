```text
Open Codex, Claude Code, or any coding agent and paste this:

"Download this GitHub repo and open the app for me:
https://github.com/rishabh2d/mac-sys-settings-2

After cloning it, read README.md, CONTRIBUTING.md, AGENTS.md, FRIEND_ONBOARDING.md, and SHARE_WITH_FRIENDS.md. Then greet me warmly, give me a short breakdown of what the app does, open the Xcode project/app if possible, and ask what Mac setting I wish existed.

If I only have an idea, help me submit a GitHub Issue using the Setting idea template. If I want to brainstorm loosely, help me start a GitHub Discussion. If I want to build the feature, help me make a branch or fork and submit a pull request.

Do not push to main. All settings go through owner/admin review before becoming public."
```
